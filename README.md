# MISSION CONTROL

**An Educational Space Mission Design Simulator**

MISSION CONTROL is an interactive educational game developed with Godot 4 and GDScript. Players take the role of a space mission designer, build spacecraft, manage resources, select launch vehicles and plan missions to different destinations.

## Features

- Four mission categories:
  - Earth Observation
  - Lunar Exploration
  - Mars Exploration
  - Deep Space Exploration
- Spacecraft construction and component selection
- Mass, power and budget management
- Launch vehicle and orbit selection
- Interactive mission simulation
- Mission Control interface
- Mission results and history
- Sandbox mode

## Built With

- Godot 4
- GDScript

## Platform

Windows Desktop

## Educational Purpose

The project introduces basic aerospace engineering concepts through interactive gameplay. Its calculations and mission systems are simplified educational models and are not intended for professional spacecraft engineering or real mission planning.

## Project Status

Developed as part of NASA Space Apps Challenge 2026.
